# Click Me If You Can

A tiny browser game about trying to click a button that really does not want to be clicked.

Move your pointer toward the button and it will dodge. Keep trying to click it, or give up.

## Play

Open `index.html` in a modern browser. No installation, build step, or dependencies are required.

## Controls

- Move the mouse or touch pointer near the button to make it dodge.
- Tap near the button to trigger a dodge.
- Select **I Give Up** to stop wasting time.
- Select **Play Again** if you don't have anything to do.

## What's Included

- Increasingly chaotic reactions the more you chase
- Changing button labels and taunting messages
- Elapsed-time tracking and a results screen
- Responsive layout and reduced-motion support
